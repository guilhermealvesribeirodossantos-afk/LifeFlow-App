LIFEFLOW ANDROID — PROJETO OFICIAL 1.0

Este projeto transforma o site LifeFlow em um aplicativo Android real.
O site está incluído dentro do APK, portanto o app abre sem depender do GitHub Pages.

IDENTIDADE:
Nome: LifeFlow
Package ID: com.lifeflow.app
Versão: 1.0
Version Code: 1
Min Android: 8.0 (API 26)
Ícone: nova logo LifeFlow

O QUE JÁ ESTÁ PRONTO:
- site LifeFlow dentro do app
- JavaScript/localStorage
- navegação
- seletor de arquivo para restauração
- tema preto/verde
- ícone Android em todas as densidades
- tela cheia sem barra de título
- botão voltar do Android integrado

COMO GERAR O APK:
1. Instale Android Studio no computador.
2. Extraia este ZIP.
3. Abra a pasta LifeFlow_Android_Official no Android Studio.
4. Aguarde o Gradle terminar a sincronização.
5. Vá em Build > Build App Bundles or APKs > Build APK(s).
6. O APK de teste será criado em:
   app/build/outputs/apk/debug/app-debug.apk

PARA PLAY STORE:
Gere um AAB assinado:
Build > Generate Signed Bundle / APK > Android App Bundle.

TESTE:
Ao instalar, procure o ícone LifeFlow na tela do celular.
O aplicativo deve abrir diretamente na tela do LifeFlow.
