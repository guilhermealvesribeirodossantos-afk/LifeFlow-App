LIFEFLOW — GERAR APK PELO GITHUB

Este projeto já possui GitHub Actions configurado.

COMO USAR:

1. Crie um NOVO repositório no GitHub.
   Sugestão de nome:
   LifeFlow-App

2. Extraia este ZIP no computador.

3. Envie TODO o conteúdo da pasta LifeFlow_Android_GitHub_Build
   para a RAIZ do novo repositório.

IMPORTANTE:
A pasta .github precisa ser enviada também.
Dentro dela existe:
.github/workflows/build-apk.yml

4. Depois do upload, entre no repositório.

5. Clique na aba:
   Actions

6. Na lateral, escolha:
   Gerar APK LifeFlow

7. Clique:
   Run workflow

8. Escolha a branch main e clique novamente:
   Run workflow

9. Aguarde o processo terminar.
   Quando aparecer um círculo verde com ✓, abra a execução.

10. Desça até:
    Artifacts

11. Clique em:
    LifeFlow-APK

12. O GitHub vai baixar um ZIP.
    Extraia esse ZIP.

13. Dentro estará:
    LifeFlow-1.0.apk

14. Envie esse APK para seu celular e instale.

OBSERVAÇÃO:
Esse primeiro APK é uma versão DEBUG instalável para teste.
Depois que o LifeFlow for aprovado no celular, podemos criar
a versão RELEASE ASSINADA pelo próprio GitHub, própria para
distribuição/publicação.
